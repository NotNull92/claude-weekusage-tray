# ClaudeWeekUsageTray

Небольшая программа в области уведомлений Windows, показывающая, сколько
осталось от лимита вашей подписки Claude Code.

Число в области уведомлений — это **процент остатка пятичасового лимита**.
По щелчку открывается панель с обоими окнами лимита и временем их сброса.

## Что она делает и чего не делает никогда

Она показывает расход. И только.

Единственные данные, которые она хранит, — это четыре числа, которые Claude Code
и так передаёт своей команде строки состояния: использованный процент и время
сброса для пятичасового и для семидневного окна.

Она **не**:

- читает `~/.claude/.credentials.json`, диспетчер учётных данных Windows,
  хранилище браузера или ключ API из переменных окружения;
- читает и не сохраняет токен OAuth, идентификатор сессии или историю переписки;
- обращается к `api.anthropic.com` или любой другой сетевой службе;
- ставит автообновление, не прописывается в автозагрузку и не шлёт телеметрию.

Входа в аккаунт здесь нет, потому что входить некуда. За вход отвечает Claude
Code, а эта программа лишь принимает числа, которые он сам присылает. Полное
описание границы и способы проверить её самостоятельно — в
[SECURITY.md](SECURITY.md).

## Требования

- Windows 10 или 11, 64-разрядная
- Claude Code установлен, выполнен вход, и он действительно запущен

Данные о расходе приходят только пока Claude Code работает. Пока он закрыт,
ничего не обновляется само по себе, и программа честно об этом говорит, а не
делает вид, что показания свежие.

## Установка

1. Скачайте ZIP из раздела релизов и распакуйте туда, где собираетесь его
   держать, например `C:\Tools\ClaudeWeekUsageTray`. Внутри всего два файла:
   `ClaudeWeekUsageTray.exe` и `uninstall.cmd`.
2. Сверьте загрузку с файлом `SHA256SUMS-v*.txt` из того же релиза:

   ```powershell
   Get-FileHash .\ClaudeWeekUsageTray.exe -Algorithm SHA256
   ```

3. Запустите `ClaudeWeekUsageTray.exe`.

   Claude Code нужно сказать, чтобы он присылал расход, поэтому при запуске
   программа проверяет, настроено ли это, и предлагает настроить, если нет:

   <img src="docs/first-run.png" width="404" alt="Окно первого запуска с предложением подключить Claude Code">

   Выберите **Connect** — программа сделает резервную копию файла настроек и
   запишет параметр. Если у вас уже есть своя команда строки состояния, она
   сначала скажет об этом и оставит вашу команду работать.

4. Пользуйтесь Claude Code. Число появится, как только он отрисует строку
   состояния, то есть сразу после первого же сообщения.

Пока не пришли первые данные, в трее отображается `--`. Это честное состояние,
а не ошибка.

Если предпочитаете настроить всё сами или хотите сделать это скриптом, есть
команда, которая делает то же самое без вопросов:

```powershell
.\ClaudeWeekUsageTray.exe --setup
```

Claude Code запоминает путь, который надо запускать, поэтому перемещение папки
разрывает связь. Запустите программу с нового места — она это заметит и
предложит переключить Claude Code на новый путь. То же предложение появится,
если распаковать новый релиз в другую папку. Только сначала **завершите уже
запущенную копию через Exit в меню**, иначе новая копия не покажет окно, а
просто откроет панель работающей копии.

### Исполняемый файл не подписан

Файл не имеет цифровой подписи. При первом запуске Windows SmartScreen выдаст
предупреждение. Если это неприемлемо, соберите программу сами через `build.cmd`;
для сборки нужны только инструменты C++ из Visual Studio.

## Как показать значок

Windows 11 по умолчанию прячет новые значки за стрелкой. Чтобы закрепить:

**Параметры → Персонализация → Панель задач → Другие значки в области
уведомлений**, затем включите **ClaudeWeekUsageTray**.

До этого значок находится в списке, который открывается по нажатию на `^`
рядом с часами.

## Как пользоваться

| Действие | Результат |
| --- | --- |
| Щелчок левой кнопкой по значку | Показать или скрыть панель |
| Щелчок правой кнопкой по значку | Меню с **Show panel** и **Exit** |
| Повторный запуск программы | Откроет панель уже работающей копии |
| Закрытие панели | Скрывает панель, программа продолжает работать |
| **Exit** в меню | Завершает программу |

Панель показывает остаток по обоим окнам, время их сброса и момент, когда
числа пришли в последний раз. Если давно ничего не приходило, панель прямо об
этом пишет, а число в трее тускнеет. Устаревшее значение никогда не выдаётся за
свежее показание.

## Если строка состояния уже занята

Claude Code допускает лишь одну команду `statusLine`, поэтому добавление всегда
означает замену. Окно при запуске говорит об этом и спрашивает, прежде чем
что-либо трогать, а `--setup` просто отказывается и сообщает, что он собирался
сделать:

```powershell
.\ClaudeWeekUsageTray.exe --setup
```

Чтобы сохранить свою команду и добавить трей поверх неё:

```powershell
.\ClaudeWeekUsageTray.exe --setup --wrap-existing
```

Ваша команда по-прежнему запускается, получает ровно тот же ввод, и её вывод
печатается без изменений. Программа лишь дополнительно передаёт в трей те самые
четыре числа. Исходная команда записывается, чтобы её можно было вернуть.

В обоих случаях перед записью `settings.json` сохраняется как
`settings.json.cwut-backup-<метка времени>`, а прочие ваши ключи, например
`padding`, остаются на месте.

Чтобы отменить:

```powershell
.\ClaudeWeekUsageTray.exe --remove-statusline
```

Если запись `statusLine` имеет вид, который программа не распознаёт, она ничего
не меняет и печатает строки, которые нужно добавить вручную.

## Уборка дублирующихся записей в трее

Windows запоминает запись области уведомлений отдельно для каждого пути к файлу,
поэтому после переноса или пересборки в списке настроек могут остаться старые
записи. Посмотреть их:

```powershell
.\ClaudeWeekUsageTray.exe --cleanup-tray-icons
```

Удалить устаревшие:

```powershell
.\ClaudeWeekUsageTray.exe --cleanup-tray-icons --apply
```

Затрагивается только `HKEY_CURRENT_USER\Control Panel\NotifyIconSettings`,
только записи, чей исполняемый файл — `ClaudeWeekUsageTray.exe`, и только в
вашей учётной записи. Сначала пишется резервная копия `.reg`, так что действие
обратимо, и ни один файл не удаляется.

## Удаление

```powershell
.\uninstall.cmd
```

Скрипт завершает значок в трее, возвращает настройку строки состояния в прежний
вид и очищает записи области уведомлений, предварительно сохранив копию `.reg`.
Файлы он не удаляет, поэтому папку уберите сами, а если резервные копии не
нужны — удалите и `%LOCALAPPDATA%\ClaudeWeekUsageTray`.

Больше ничего не остаётся. Нет ни установщика, ни службы, ни разделов реестра,
кроме той записи области уведомлений, которую Windows заводит для любой программы
в трее.

## Сборка из исходников

```powershell
.\build.cmd
.\build\ClaudeWeekUsageTray.exe --self-test
pwsh -File .\tools\security-scan.ps1
```

Нужен Visual Studio 2019 или новее с компонентом **Разработка классических
приложений на C++**. Других зависимостей нет: нативный Win32 и C++17, статическая
CRT, без .NET и без сторонних библиотек. Всё линкуется в один исполняемый файл.
`build.cmd clean` удаляет результаты сборки.

Собрать ZIP релиза и его `SHA256SUMS-v*.txt`:

```powershell
pwsh -File .\tools\package.ps1
```

## Как это устроено

При каждой отрисовке Claude Code запускает свою команду `statusLine` и подаёт ей
на стандартный ввод данные в формате JSON. Эта команда — тот же самый файл,
запущенный как `ClaudeWeekUsageTray.exe --statusline`. В этом режиме он берёт из
данных только четыре числа и отправляет их работающему трею по TCP через
локальную петлю. Соединение защищено 256-битным токеном, который лежит в файле,
доступном для чтения только вашей учётной записи. Всё остальное содержимое не
читается, не сохраняется и не пересылается.

Одна тонкость, если решите проверить вручную: PowerShell не ждёт программу
подсистемы GUI, поэтому `echo '{...}' | .\ClaudeWeekUsageTray.exe --statusline`
вернёт приглашение раньше, чем придёт вывод. Claude Code читает канал правильно.
Чтобы увидеть результат своими глазами, запускайте через `cmd /c`.

Всё построено на событиях. Трей обновляется, когда Claude Code что-то присылает.
30-секундный таймер внутри трея лишь перерисовывает то, что уже есть, чтобы число
потускнело, а формулировка сменилась на «устарело» вовремя; он ничего не
запрашивает.

Остальное описано в [DESIGN.md](DESIGN.md).
